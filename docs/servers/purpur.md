# Purpur

Paper, plus a deep drawer of gameplay configuration: grinding tweaks, entity
settings, and knobs Paper never exposed. Choose it when your players ask for
behavior vanilla Paper cannot do.

Same shape as Paper here: Java 21+, EULA checkbox, checksum-verified jar
from PurpurMC, `server.properties` written for you, Minekube tunnel
supported. Paper plugins generally run unchanged in `plugins/`.
